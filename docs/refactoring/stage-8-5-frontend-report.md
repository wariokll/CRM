# Этап 8.5 — frontend data access

## 1. Что сделано

Сетевые операции вынесены из дочерних компонентов в feature `queries.ts`; страницы передают данные и callbacks:

- `KnowledgeArticleView` получает callback загрузки вложений.
- `AccessDialog` получает список сотрудников и callback изменения доступа.
- `BoardLayoutDialog` получает callback сохранения раскладки.
- `BoardArchiveDialog` получает callbacks загрузки архива и восстановления карточки.
- `StoreDetails` получает callbacks загрузки и сохранения реквизитов доступа.

Добавлена страница `AccessDeniedPage`. Для существующих закрытых разделов сохраняются те же правила доступа из `buildNavigation`; переход по известному закрытому адресу показывает страницу запрета, неизвестные адреса по-прежнему перенаправляются на главную. Компонента `RequireRole` в текущей ветке и истории до неё не было.

Основные компоненты страниц оставлены контейнерами. Файлы свыше 200 строк, затронутые передачей callbacks: `BoardsPage.tsx` (662 строки), `KnowledgePage.tsx` (670), `StoresPage.tsx` (216), `StoreDetails.tsx` (216), `BoardArchiveDialog.tsx` (222) и `BoardLayoutDialog.tsx` (251). Их UI и бизнес-логику дополнительно не дробили: подэтап меняет границу сетевого доступа, а дополнительное разбиение затронуло бы структуру представления без необходимости.

## 2. Результат `npm.cmd run verify`

Полный прогон прошёл: проверка кодировки, TypeScript, ESLint и Prettier; frontend — 4 файла/10 тестов; backend — 37 файлов/116 тестов. Frontend coverage: statements 45.39%, branches 38.65%, functions 32.74%, lines 46.03%. Backend coverage: statements 85.14%, branches 66.81%, functions 87.59%, lines 86.27%. Frontend и backend production builds, SPA fallback и Playwright smoke прошли; E2E — 11/11. Проверка Prisma не обнаружила ожидающих миграций или расхождений схемы.

Во время промежуточного прогона drag-and-drop smoke завершился таймаутом при поиске второй колонки; отдельный повтор этого сценария прошёл, а финальный полный прогон прошёл 11/11. Известная нестабильность knowledge reload smoke описана в отчёте 8.3; финальный прогон также прошёл.

Дополнительное дробление перечисленных крупных компонентов не выполнялось, чтобы не менять их внутреннюю структуру сверх передачи данных и callbacks.
