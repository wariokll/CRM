- Установленные миграции тестовой базы проверяются перед API-тестами. Новых миграций и изменений `schema.prisma` нет.

## Зафиксированное исходное отклонение

Prisma обнаруживает известное расхождение между применённой миграцией и `schema.prisma`: длины `organization_contacts.full_name` и `organization_contacts.phone`. Этап запрещает изменение схемы БД, поэтому расхождение оставлено без изменений и явно разрешено в проверке схемы. Любое другое расхождение завершает runner ошибкой.

Регистрация с ИП-именем в текущем backend сохраняет тип организации `OTHER`; тест фиксирует фактическое поведение без исправления бизнес-логики.

## Границы этапа

Бизнес-маршруты пока используют существующий singleton Prisma-клиент; фабрика приложения вводит точку композиции и позволяет тестировать HTTP без открытия listener. Поведение маршрутов в этом этапе не переписывалось. Изменения окружения, существовавшие до начала этапа (`backend/package.json`, `stop-crm.ps1`), сохранены и отдельно отмечены в инвентаризации этапа 0.
