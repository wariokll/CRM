# Servio CRM

Адаптивный интерфейс CRM для сервисного отдела. В текущем прототипе доступны:

- обзор заявок и показателей;
- фильтрация срочных заявок по статусу;
- карточка заявки и смена её статуса;
- создание срочной заявки в демо-данных;
- календарь запланированных работ и блок модерации.

## Запуск

Требуется Node.js 20+.

```powershell
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Backend и база данных

Добавлен API в папке `backend`: Express, Prisma/MySQL, JWT access + refresh cookie, bcrypt, проверка ролей и AES-256-GCM для AnyDesk/ОФД/налоговой. Секреты не возвращаются в обычном списке точек — только через защищённый маршрут конкретной точки.

1. Установите Docker Desktop и запустите MySQL: `docker compose up -d`.
2. Скопируйте `backend/.env.example` в `backend/.env`, замените все секреты и пароль администратора.
3. В `backend` выполните `npm run prisma:migrate`, затем `npm run seed` и `npm run dev`.

Тест шифрования запускается командой `npm test` из папки `backend`.
